# 3. Main Modules

| Module | Purpose |
|--------|---------|
| Organization & Academy Management | Manage the org and its academies/branches |
| Athlete Management | Athlete records and profiles |
| Sports, Gym & Fitness Programs | Define sports/departments and programs offered |
| Batches & Scheduling | Group athletes into batches with schedules |
| Attendance | Session-based attendance tracking |
| Training Plans | Coach-authored training plans per athlete/batch |
| Performance | Skill and fitness assessments over time |
| Practice Levels | Level 1–5 progression per sport |
| Physician Sessions | Medical review, clearance status, recommendations |
| Nutrition | Nutrition plans and guidance |
| Tournaments | Competition management |
| Academy Transfers | Move an athlete between academies, preserving history |
| Memberships & Payments | Billing, membership plans, payment records |
| Notifications | Alerts to athletes/coaches/guardians |
| Reports | Cross-cutting reporting for admins/coaches |
| Roles & Permissions | Role-based access control across the platform |

See [Athlete Lifecycle](flows/athlete-lifecycle.md) for how these modules connect across a
single athlete's journey.
